# BLEX Server

Fastify serves React SSR pages, HTTP APIs, and static assets. Prisma manages the SQLite schema. Domain code lives in `src/features/`, route registration in `src/routes/`, and shared HTTP helpers in `src/platform/`.

Run `pnpm install` and `pnpm dev` from the repository root. See the [development conventions](../../docs/DEV_CONVENTION.md) and [backend guide](../../docs/BACKEND_GUIDE.md) for code layout and checks.
